# 明日方舟日服汉化

[简体中文](README.md) | [繁體中文](README.zh-TW.md)

由 **芽咩洛（yameroooo1111）** 维护的《明日方舟》Windows 日服简体中文修复版。

本项目基于繁花掠影的 [ArknightsLocalizationToolkit](https://github.com/2845086683/ArknightsLocalizationToolkit) 二次开发，补修词库与插件后分享给大家。不是游戏官方工具，也不是原作者发布的新版本。

## 下载与使用

从本项目 [Releases](https://github.com/yameroooo1111/Arknights-JP-ZH/releases) 下载 `Arknights-JP-ZH-v2.1.10-win-x64.zip`，完整解压后运行 `ArknightsJPZH.exe`。

1. 点击“选择游戏”，选择日服安装目录中的 `Arknights.exe`。
2. 正常退出游戏，点击“安装 / 修复并启动”。程序会先校验文件并备份需要替换的文件，完成后启动游戏。
3. 平常可以按“启动游戏”，也可以沿用原本的游戏启动方式。游戏更新覆盖插件时，再执行一次安装／修复。

启动器直接使用随包的日服词库，无需选择区服或词库。主界面只保留选择游戏、安装／修复、启动游戏、卸载汉化与查看记录。

支持 Windows 10/11 64 位，需要已下载完整资源的日服 PC 客户端。一般安装不需要另装 Python、Conda 或申请翻译 API Key。翻译查询在本机完成；初次启动的框架依赖组件可能仍需下载。

请保留整个解压文件夹，不能只拿走 EXE。第一次生成运行环境可能需要一些时间。需要还原时，正常退出游戏后使用“卸载汉化”。若界面提示游戏仍在运行，正常退出后会自动刷新；切回启动器时也会重新检测。

## 从旧版更新

下载完整 2.1.10 包并解压到新文件夹，打开新启动器，选择游戏后重新安装即可，不必逐版更新。新版启动器固定使用本包的“明日方舟日服汉化 · 2.1.10”，不会沿用旧版的词库选择。

每次打开启动器，会在后台检查本项目的 GitHub 正式 Release。发现较新版本时，可按“前往下载”打开发布页，或按“稍后”继续使用。更新请下载完整 Windows 包，程序、插件和词库一起更新，不再单独更新词库，也不会自动替换正在使用的程序。网络检查失败不弹窗，不影响安装和启动。

设置保存在 `%LOCALAPPDATA%/ArknightsJPZHRefined/launcher.json`，不会覆盖原工具的设置。切换工具前请正常退出游戏。

## 为什么建立这个版本

原版当时尚未更新到我使用时需要的内容，因此我在原作者的基础上自行补修，顺便分享给有相同需求的玩家。

本版本沿用国服的简体中文与游戏术语，没有将游戏整套改成繁体中文。本包与启动器面向日服，不附美服词库。

仍可能有漏翻。无法确定对应的内容会保留原文，避免误译。反馈时请提供画面、所在功能、干员／模组／关卡名称，以及游戏与工具版本；请遮住账号信息。
