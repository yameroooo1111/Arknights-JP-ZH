# 明日方舟日服漢化

[简体中文](README.md) | [繁體中文](README.zh-TW.md)

由 **芽咩洛（yameroooo1111）** 維護的《明日方舟》Windows 日服簡體中文修復版。

本專案基於繁花掠影的 [ArknightsLocalizationToolkit](https://github.com/2845086683/ArknightsLocalizationToolkit) 二次開發，補修詞庫與外掛後分享給大家。不是遊戲官方工具，也不是原作者發布的新版本。

## 下載與使用

從本專案 [Releases](https://github.com/yameroooo1111/Arknights-JP-ZH/releases) 下載 `Arknights-JP-ZH-v2.1.10-win-x64.zip`，完整解壓後執行 `ArknightsJPZH.exe`。

1. 點擊「选择游戏」，選擇日服安裝目錄中的 `Arknights.exe`。
2. 正常退出遊戲，點擊「安装 / 修复并启动」。程式會先校驗檔案並備份需要替換的檔案，完成後啟動遊戲。
3. 平常可以按「启动游戏」，也可以沿用原本的遊戲啟動方式。遊戲更新覆蓋外掛時，再執行一次安裝／修復。

啟動器直接使用隨包的日服詞庫，無需選擇區服或詞庫。主畫面只保留選擇遊戲、安裝／修復、啟動遊戲、卸載漢化與查看記錄。畫面按鈕使用簡體中文。

支援 Windows 10/11 64 位元，需要已下載完整資源的日服 PC 客戶端。一般安裝不需要另裝 Python、Conda 或申請翻譯 API Key。翻譯查詢在本機完成；初次啟動的框架相依元件可能仍需下載。

請保留整個解壓資料夾，不能只拿走 EXE。第一次產生執行環境可能需要一些時間。需要還原時，正常退出遊戲後使用「卸载汉化」。若畫面提示遊戲仍在執行，正常退出後會自動刷新；切回啟動器時也會重新偵測。

## 從舊版更新

下載完整 2.1.10 包並解壓到新資料夾，開啟新啟動器，選擇遊戲後重新安裝即可，不必逐版更新。新版啟動器固定使用本包的「明日方舟日服汉化 · 2.1.10」，不會沿用舊版的詞庫選擇。

每次開啟啟動器，會在背景檢查本專案的 GitHub 正式 Release。發現較新版本時，可按「前往下载」開啟發布頁，或按「稍后」繼續使用。更新請下載完整 Windows 包，程式、外掛和詞庫一起更新，不再單獨更新詞庫，也不會自動替換正在使用的程式。網路檢查失敗不彈窗，不影響安裝和啟動。

設定儲存在 `%LOCALAPPDATA%/ArknightsJPZHRefined/launcher.json`，不會覆蓋原工具的設定。切換工具前請正常退出遊戲。

## 為什麼建立這個版本

原版當時尚未更新到我使用時需要的內容，因此我在原作者的基礎上自行補修，順便分享給有相同需求的玩家。

本版本沿用國服的簡體中文與遊戲術語，沒有將遊戲整套改成繁體中文。本包與啟動器面向日服，不附美服詞庫。

仍可能有漏翻。無法確定對應的內容會保留原文，避免誤譯。回報時請提供畫面、所在功能、幹員／模組／關卡名稱，以及遊戲與工具版本；請遮住帳號資訊。
